The World in One Day — 20 November 2026: a front-page image summing up Friday 20 November 2026's world news, 36 numbered stories from six continents, with a dotted world map carrying a numbered pin for each story.

The image names its day in a red banner (Friday 20 November 2026) and
each story is readable on its own: a headline plus a one- or two-line
summary, so a viewer who missed the day can tell what happened from
the image alone.

## The stories

The full-day edition, researched across 20 November 2026 from the
One Turn day page, Just Security Early Edition, AP, BBC and The Hindu
reporting via those digests, ATP Tour results and the Jagran Josh
21 November round-up — only events that happened, or were first
reported, on 20 November 2026. Leading stories: Anthropic's record
$81.3bn IPO, the Shenzhen peace declaration signed by Trump, Xi and
Putin, the ICJ's Myanmar genocide ruling, the Houthi strike on Riyadh
and Russia's overnight strike on Kyiv.

## The program

`main.py` (Python 3, standard library only) copies the bundled
`entry.png` to `/output/entry.png`, verifying the PNG signature, the
1 MiB size limit, and that the written bytes match the bundle exactly.
It uses no network, and both runs write identical bytes.

## Run it

```sh
python3 main.py
```
